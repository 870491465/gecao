橘猫手推割草机 V03：车轮与滚筒联动版

walk_preview.gif：小猫步行动作＋前滚筒旋转＋左右车轮胎纹滚动。
frames：24张512×768透明整帧，20fps，1.2秒无缝循环。所有帧画布/比例/根位置固定。
reel_frames：对应的24张独立透明滚筒层，同尺寸、同位置，可单独播放。
滚筒为横轴转动的六根横杆，按圆周投影上下运行，保留镂空间隙；非整体贴图平面旋转。左右车轮沿轮面循环移动胎纹，固定轮毂与外轮廓，轮轴固定，一圈1.2秒；外侧护架、发动机、推杆与握爪固定。每帧5度，一圈3.6秒；六杆60度对称，1.2秒循环转120度恰好接续。
Cocos：整帧或独立滚筒层二选一，不要叠加重复滚筒。透明整帧保持固定画布，关闭逐帧自动裁边造成的偏移。
角色继续沿用V01轻步形变；滚筒是程序绘制的简化动画层，与原画金属细节有差异。未做Cocos实机验证。
build.py可复建，需要Pillow、NumPy、SciPy。
