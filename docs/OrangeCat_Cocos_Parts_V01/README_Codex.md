# 橘猫分层 PNG：Cocos 接入包 V0.1

## 本次实际交付

textures/ 下四张独立 RGBA PNG：

- cat_body_feet.png：头部、身体与双脚固定底层。
- cat_right_arm_sickle.png：右臂、握持爪与向内勾的镰刀，一体层。
- cat_left_arm.png：左臂与爪。
- cat_tail.png：尾巴。

源头为已确认的 imagegen 部件图。按 alpha 主体分区拆分，保留原图颜色和半透明毛边；完全透明像素的 RGB 已清零。图中显示的黑底或彩色背景不是 PNG 实际背景。无需再次抠图。

parts_config.json 给出实际像素尺寸、建议支点、位置、缩放与绘制顺序。previews/assembled_reference.jpg 是按这些数值制作的静态拼装检查图，不是游戏纹理，也不是 Cocos 截图。

## 本地 Codex 接入要求

先检查工程锁定的 Cocos 版本，按现有 2D Sprite 流程导入，不升级引擎。沿用 V0.2 的固定朝向、地图向下移动和自动收割逻辑。不要恢复 3D 自由移动玩法。

1. 新建 CatRoot，固定在角色脚底中心。四个部件作为独立子节点，先不播放动画。
2. 按 JSON 的 size_px 设置原始显示尺寸；按 anchor_normalized_bottom_left 设置支点。PNG 的像素坐标从左上计算，但提供的归一化锚点已转换为左下原点。
3. position_from_feet_root_y_up 是相对 CatRoot 的位置，X 向右、Y 向上，单位为设计像素。local_scale 是各部件静态拼装比例。所有部件完成拼装后，统一缩放 CatRoot 到游戏里合适的大小，勿分别按包围盒自动缩放。
4. 绘制顺序由后至前：左臂、右臂与刀、身体与脚、尾巴。身体覆盖肩部截口；尾根叠在身体上。具体节点排序使用本项目现有渲染方式。
5. 禁止自动裁透明边距后丢掉偏移。首轮使用完整 PNG 尺寸；若启用图集裁切，需正确处理原始尺寸和偏移。
6. 保留 alpha，按普通带透明度的 2D 素材显示。检查浅、深背景上的毛边。不要把预览 JPG 用作角色。
7. 对照 assembled_reference.jpg 核对拼装。建议锚点为视觉选取，不是自动骨骼识别结果；可以小范围微调，但调完要把数值写回配置。

## 动作起步与限制

此包不含动画文件、Prefab、骨骼或 .meta，也没有完成 Cocos 实机验证。

本版身体和双脚在一层：挥刀测试时固定它们，不旋转、缩放整张身体来冒充扭腰，否则双脚也会动。可先仅让右臂以肩部支点做小幅蓄力、挥出、回收，让左臂和尾巴轻微配合。不要用负缩放把右手镜像成左手，不要在不同生成姿势间硬切换。

建议一轮约 1 秒：蓄力 0.2 秒、挥出 0.2 秒、余势 0.15 秒、回收 0.45 秒。角度必须根据实际刀刃路径调节，暂不提供未经验证的大幅度角度值。侧面关节图层只能表现平面转动；要实现跨身体前方的大幅度空间横扫，需补适配透视的手臂关键帧或更细分层，不能靠任意旋转一张图保证正确。

右手和镰刀合并可避免握持脱离，但不能直接独立换镰刀；升级阶段应替换整层，或后续制作拆开的握爪和工具。头部、身体、双脚尚未独立，步行动画和扭腰需要后续素材。

## 联调验收

- 无地面滑步：挥刀时脚底像素位置保持不变。
- 右手始终持刀，刀尖向内勾，不穿头或身体。
- 手臂肩部、尾巴根部没有显著断口；不要让关节截面暴露。
- 刀刃扫到作物才触发已有切割事件；回收阶段不重复加金币。
- 暂停时停止工作动画，开始后继续；此包不修改现有经济和存档。
- 先用单只猫验证，再接入滚动田地。请反馈动作录屏与实际参数。
