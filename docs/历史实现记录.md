## 打开与运行

1. 使用已安装的 Creator **3.8.8** 打开本目录，等待资源导入。
2. 双击 `assets/scenes/Main.scene`，点击编辑器顶部预览。
3. 首次 0 金币、1 级，点击一次“开始收割”。此后自动换垄、换轮；升级仍需点击购买。重开或返回前台显示继续入口。

场景由序列化的 **2D Canvas + 正交 UI Camera + HarvestGame** 启动；运行时生成分层节点。不是网页框架实现，也没有 3D 模型。

独立动画入口：`assets/scenes/ScytheLab.scene` 为一级镰刀；`assets/scenes/MachineLab.scene` 为四级滚筒机械。它们使用临时内存进度，不加载或覆盖 Main 存档。DEV 面板可进一步切换六级，二级可观察压缩平面内旋转刀盘。

橘猫 **Walk V02 六层 PNG** 已接入一级、二级，身体与双腿分离，步态按地图距离同步。`assets/scenes/CatPartsLab.scene` 可检查静态、仅走路、走割、慢速与单步。当前参数、素材限制和实际录屏见 [V02 接入记录](docs/CatWalk_V02_接入记录.md)；[V01 记录](docs/CatParts_V01_接入记录.md)保留为历史。

镰刀的逻辑和美术共用 `V03Motion.ts / ManualSickle.ts` 的握点、内刃轨迹与接触相位。蓄力 0.2s、挥出 0.2s、余势 0.15s、回收 0.45s。挥割期间双脚停稳，回收推进时按距离迈步，不结算第二次。机械仅在推进跨过割台线时结算。每次切断同步更改 mask、余额、田进度、总单元数和总收入；浮字、金币粒子及声音均不发钱。

单元 ID 为 `等级:轮次:垄号:行号:列号`，已完成行由 row 隐式表示，当前行逐列用 mask 表示，不需保存整田 3600 个布尔值。渲染池每次绑定新 ID 都重置切割和动画状态。地块与田边使用单个批量 Graphics，不创建整田地块节点。浮字最多 3 组，金币最多 5 个，0.4 秒合并收入反馈。

## 自动检查与构建

在项目根目录 PowerShell：

```powershell
./tools/verify.ps1
./tools/build.ps1 -Platform web-mobile
node tools/serve.cjs
# 浏览器访问 http://127.0.0.1:8092
./tools/build.ps1 -Platform wechatgame
# 正式构建隐藏 DEV
./tools/build.ps1 -Platform wechatgame -Release
```

如编辑器安装路径不同，对两个 PowerShell 脚本传 `-CreatorRoot`。脚本调用现有 3.8.8 自带 TypeScript，不安装其他版本。`skipLibCheck` 仅跳过引擎发行包自身声明中的缺失 WebGPU/内部类型，项目代码仍检查。

构建使用 `tools/build-web.json / build-wechat.json`，入口 UUID 固定。微信配置中的 `touristappid` 仅用于测试构建，不能发布；在 Creator 构建面板或配置文件中换成自己的 AppID，再用微信开发者工具导入 `build/wechatgame`。必须在真机检查胶囊安全区、音频解锁、后台与存储行为。

构建方法遵循 [Cocos 3.8 命令行发布文档](https://docs.cocos.com/creator/3.8/manual/zh/editor/publish/publish-in-command-line.html)。构建成功码为 36。日志写入 `temp`，原始构建目录在 `build`（均为可再生文件，不纳入版本控制）。

前五级实际切割均使用 `Grass_Field_Batch02/textures/fx_leaf.png` 与 `fx_stem.png` 触发碎草飞散；机器档位使用更大的散射范围。粒子旋转、受重力下落、0.4秒淡出，并通过最多48个节点的对象池复用。已收割单元不会重复触发；特效不结算金币，暂停及切后台冻结。`tools/test-grass-debris.cjs` 验证六级真实切割、动画、回收与收入独立性。

一级镰刀已接入 `Sickle_Slash_Addon/fx_sickle_slash.png` 原图：在实际接触草丛时沿刀刃轨迹显示，保持544:180比例，匹配向左挥割方向，0.12秒淡入、保持、淡出；每刀只触发一次。暂停、切后台或升级会清除刀光，读档不会重播已结算的挥刀。刀光独立于金币结算。`tools/test-sickle-slash.cjs` 验证接触时机、跟随、单刀去重和中断恢复。

临时搞笑录屏入口为 `/?funny=1`：从独立的一级演示进度开始，点击开始后前2秒正常，随后9秒逐渐向右斜走，走到田外后继续挥刀。猫和阴影一起移动；暂停与后台停止演示计时。正式存档在此模式下不写入，升级气泡隐藏。设置里的“搞笑录屏：已开启 · 点此恢复正常”会还原原等级、金币、田进度和正常位置，并移除网址参数。普通入口默认正常模式；设置中也可主动开启演示。`tools/test-funny-recording.cjs` 验证录屏动作和完整恢复。

第五级为全屏联合收割机：第四级花费38400金币升级。车身、驾驶舱、小猫和车轮保持第四级0.85比例；原始24帧通过 `wide-header.effect` 分离车身与滚筒，滚筒仅横向扩展1.26倍，两端各留约18像素以完整显示旋转外环，纵向尺寸和后轮贴地锚点不变，车顶不会随滚筒拉伸。720宽草田铺满屏幕，六垄草各两个结算切片，每行12个单元，单元12金币、速度3行/秒；每田100行，一次横向覆盖整屏，无需侧向换垄。现有五级存档保留田进度、金币、已收割切片。验证：`tests/fullscreen-harvester.test.cjs` 与 `tools/test-fullscreen-harvester.cjs`。
