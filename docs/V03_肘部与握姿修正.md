# V03 肘部与握姿修正

本次只调整右臂显示与绑定。单条草垄、草图画布、猫大小和镰刀缩放 0.21 保留；经济、购买、存档与自动收割流程不变。

发现的问题：前臂源图末端包含浅色腕部，单独握爪又包含长橙色腕部，整张串接造成重复腕部和过长前臂；上一版把整段握爪腕部算作第三段肢体。肘部选择的平面 IK 分支让前臂在身体侧面呈现向下悬挂的 U 形折弯，放大了接缝问题。此前只通过锚点重合检查，不能代表视觉上的关节和握姿正确。

本次修正：

- `V03Motion.ts`：上臂骨长 38，前臂 36，使用稳定的前向肘部分支。握爪只计算 `(280,180)` 腕部到 `(365,164)` 掌心的短距离，长袖口用于重叠，不再整体延长手臂。
- `V03Actor.ts`：前臂使用原 PNG 的 `Rect(0,0,356,232)` 显示区域，腕部参考 `(335,117)`；握爪使用 `Rect(250,0,256,360)`，裁掉多余的长袖口。只改变运行时 SpriteFrame 显示矩形，源 PNG 未修改或重绘。
- 上臂和前臂显示厚度接近，腕部保留遮盖重叠；刀柄仍由掌心覆盖，工具和掌心共用握点。头身遮挡前伸的肘部，不再让大折弯暴露在身体侧面。

实际入口：`assets/scenes/Main.scene`；也可在 `SwingSequenceLab.scene` 禁刀光、暂停与关键相位检查。实际 WebGL 截图和测量数据保存在 `docs/verification/v03-elbow-grip/`，以该目录 `build.json` 和 `results.json` 为准。现有素材仍为分层静态图，握爪没有独立的握紧/松开帧；本次不声称新增了手指屈伸或正式挥镰序列。

Creator 3.8.8 Web 构建成功（退出码 36）；实际 WebGL 检查 101 个姿势的肩肘腕掌接点和刀柄握点通过，暂停进度保持，一级连续两轮仍收入 160、无重复 ID，二级跨帧每刀收入 6。已查看无刀光的静态姿势和正常运行截图，右臂由下挂折弯改为朝前伸出。自动检查另覆盖固定骨长、1001 个姿势不翻肘、购买锁、存档和低帧率结算。真机和长期性能未验证。
