# 橘猫割草记 MVP V0.2 自动收割产品需求文档

版本：MVP V0.2｜更新日期：2026年10月28日｜工作名：橘猫割草记（暂定）

点击一次开始，看胖橘猫自动收割，金币即时到账；玩家只需点击升级，从一小垄青草和小镰刀起步，逐级获得更强设备、更大田地、新作物和更高收入。体验重点是观看收割的治愈感与成长期待。

本版替代旧版自由移动和出售玩法。实现采用Cocos 2D精灵制作2.5D斜俯视效果，猫固定在屏幕中下部，朝屏幕上方，地图向下滚动。美术以本页用户提供的欧美卡通农场参考图为准。

# 2 完整循环和运行状态

首次进入显示橘猫与一小垄青草，金币为0，设备1级，底部显示“开始收割”。点击一次后自动推进，开始按钮退为小暂停入口，底部主要位置用于下一次升级。

循环：自动收割 → 金币即时到账 → 自动换垄或开始下一轮 → 玩家攒够钱点击升级 → 原地换设备并切到更大新作物田 → 自动继续收割。

| 状态 | 地图与动作 | 收益与交互 |
| --- | --- | --- |
| 待开始 | 猫呼吸待机，地图静止 | 不产金币，可开始 |
| 收割中 | 地图向下滚动，镰刀挥动或机械运转 | 仅真实收割事件结算，可升级或暂停 |
| 换垄或换轮 | 0.5—0.8秒自动过渡，朝向不变 | 无空发收益，不需确认 |
| 升级中 | 暂停推进，约1—1.5秒换装与场景过渡 | 锁定购买，扣款一次 |
| 暂停或设置 | 地图、作物和工作动画停止；保留轻待机 | 不计收益，点击继续恢复 |
| 切后台或重开 | 保存后停止模拟 | 无离线收入，回前台点击继续 |

升级只有玩家点击才发生，金币足够不自动花钱。暂停时也可购买，购买结束保持暂停；运行中购买结束自动继续。最高级后持续自动收割，不强制结束。

# 3 固定角色和向下滚动地图

角色地面锚点位于可用画面约65%—72%高度处，按UI安全区调整；位置固定，允许动作带来少量局部位移。朝向始终为画面上方，使用后上方斜俯视素材，禁止改为对角线前进。

场景从顶部进入并向下移动。成熟作物在角色前方接近工具，切断后留下草茬，草茬继续向下移出屏幕。地面、作物、田边标记使用同一推进坐标，避免作物与地面滑动脱节。

画面结构为上部未收割作物、中部刀具接触区、下部已收割地面。猫头不能挡住镰刀刀刃；手臂和工具伸向侧前方。机械割台需露出在车身前方，猫耳和头部保留辨识度。

屏幕中只聚焦正在收割的一垄，邻垄可局部露出但不作为当前待收割目标。每垄宽度等于设备有效收割宽度，自动完整覆盖，不需要左右移动或回头补割。

田地变大以垄宽、垄长、垄数共同体现，不通过持续缩小猫或机器塞下整块地图。高等级可小幅调整统一场景缩放，但必须保持工具、作物和金币信息清晰。

每垄末端过渡到下一垄，使用淡变或田埂遮挡切换，不展示角色掉头、倒车或横向跑位。一块田收完自动进入同级下一轮，短暂保留平整地面后过渡；不弹结算窗口，不要求点击开始，不在角色脚下突然补草。

# 4 收割与金币规则

作物使用逻辑单元管理，一个逻辑单元可对应一簇多根装饰植株，只结算一次。每单元唯一键由等级、轮次、垄号、行号、列号组成，循环复用精灵不得复用结算状态。

有效切割事件同时更新：作物已收状态、当前田进度、累计收割数、金币余额与累计收入。金币增加量等于本次新收割单元数乘当前作物单价。金币动画、声音、缩放或粒子均不再次结算。

镰刀使用挥动轨迹或关键帧驱动，刀刃扫过后作物依次倾倒。机械按割台实际经过的区域结算。用推进距离跨越检测或子步处理低帧率，不能漏行或重复计数。

推进速度由收割能力约束。镰刀阶段允许“迈步接近—挥刀—继续”的节奏；机械阶段连续推进。未切断的成熟作物不能直接穿过角色移出屏幕，必要时放慢推进等待切割。

金币每次实际切断时到账，顶部余额可平滑追到真实数值。浮字按0.3—0.5秒合并，同屏最多约3组；金币飞行粒子少量代表即可。不能每根作物都生成飞行金币和音效。

整田完成只显示不阻断的轻提示；无额外金币奖励，避免经济估算混入未定义奖金。新一轮全部成熟，无生长等待门槛。

四次购买合计18480金币；按金币足够立即购买、每级余额接近0估算，达到五级需约600秒净收割时间，加换垄、换轮与升级过渡，首轮目标约10—12分钟。暂停、延迟购买和实际动画吞吐会改变耗时，须实测，不承诺固定时长。

购买规则：只买下一级；不足显示差额，不扣款。成功一次扣款并同步提升等级、设备、作物与田地配置，保留剩余金币。从新等级第一垄第一行开始，旧田未收部分不折现，不要求收完才能升级。连续点击在升级锁定期间无效，演出结束前不允许连升。

升级演出显示“新设备＋新作物田”与收益变化，不加二次确认。暂停或运行状态在演出结束后恢复。五级显示“当前最高级”；用五级收完第一整块田后显示一次轻庆祝，收割自动继续。

# 8 镰刀和机械动画规格

## 8.1 镰刀挥割

一轮约1秒：蓄力约0.2秒、快速挥出约0.2秒、余势约0.15秒、回收及迈步约0.45秒。两个手工等级可保持相近节奏，以刀幅和每刀数量表现升级。

身体、前后手臂、镰刀、腿和尾巴分层。以肩肘与握持点为支点，身体轻扭，手臂带动刀具；不得仅旋转整张猫图片。镰刀刀刃经过草丛时按扫过次序切断，切断反馈与命中音同帧触发。

镰刀可使用分层节点动画或短序列帧。确保握持不脱手、刀刃不穿脸、收回不再次结算。局部阴影和前后图层随动作合理变化。

## 8.2 机械连续收割

车身稳定，刀盘、滚筒、轮子分别运动。斜俯视圆盘不能简单旋转一张带固定椭圆透视的整体图片造成形状扭转：可在局部平面旋转后投影压缩，或使用循环帧。横向滚筒优先循环帧表现翻动，不能把整根滚筒当风车旋转。

轮子转速与地面滚动匹配。作物接近割台后朝内倾倒、截短或卷入，后面留下整齐短茬。机械车身轻微振动即可，角色耳朵与头部保持可见。

暂停时地图与工作部件同步停下，不能停止收益却继续表现收割。换垄过渡时可保留低速待机，不播放切草命中音。

## 8.3 声音与特效

镰刀为柔和有节奏的“唰”，机械为轻微连续转动与沙沙切割声。金币提示合并限频，不逐单元播放；升级使用短上扬音，整田完成只轻提示。

音效、音乐可独立关闭；震动默认关闭，设置中可开启轻反馈。特效不遮挡作物被切断的瞬间。灰盒缺正式音效时允许占位，但需标记未验收。

# 10 存档与中断

存档包括版本、金币、等级、田轮次、垄号、推进距离、当前行及局部已切单元、累计收入与收割数、首次开始标记、设置、五级完成标记。不需要角色自由坐标和库存。

至少每5秒保存普通收割快照，升级成功和切后台立即保存。金币与作物进度同时记录，不能只存金币或只存动画位置。普通异常退出允许最多5秒进度回退，但不能因此重复发钱。

升级扣款、等级切换和新田进度重置属于同一快照。演出中断后按已提交等级恢复，不重复扣款或发奖励。回到游戏需点击继续，不补算后台时间。

若项目已有旧版测试存档，应先备份并提供开发版重置入口；不把旧库存、出售收入直接迁移为新规则金币。版本不兼容时给清楚提示，不静默丢弃存档。第一版无需复杂线上迁移系统。

# 11 灰盒阶段与验收

先做两个动画样机：小镰刀割青草、机械割麦子。通过后补齐五级成长。灰盒必须使用2D节点与分层占位素材，不能继续沿旧提示词开发自由移动3D工程。

| 阶段 | 交付 | 验收重点 |
| --- | --- | --- |
| A 动作样机 | 固定猫、向下地图、镰刀与机械两种收割 | 刀碰到才断，机械部件真的在转 |
| B 自动循环 | 点开始、连续运行、换垄换轮、暂停与继续 | 不需要持续触摸，成熟作物不漏割 |
| C 完整成长 | 五级设备作物、土地扩大、自动收入、点击升级 | 一次升级同时改变四项内容 |
| D 微信体验 | UI、声音、存档、适配、性能 | 连续观看舒服，运行稳定 |

功能验收：

- 点击一次开始后不碰屏幕，至少跨过两个完整田地轮次，仍自动收割。

- 收割10个单价为3的单元严格加30金币；粒子、暂停恢复、滚动对象复用不重复结算。

- 五级土地面积、作物单价和收割能力逐级增加；当前垄全宽覆盖，无规律性漏行。

- 钱不足不扣款；连点一次购买仅升一级，设备、作物、田地、价格同步更新。

- 暂停时不推进不结算，回前台无后台补发；运行中升级自动续割，暂停中升级仍暂停。

- 完成一垄或一块田不弹需点击的窗口；没有出售、满载、摇杆或长按交互。

- 在换垄、切割关键帧和升级演出时退出重进，金币与进度一致。

- 到最高级后可以无限继续，无重复扣款或阻断。

- 五级首块完整田结束只显示一次轻庆祝，不暂停收割。

视觉验收：

- 角色固定位置、朝上；地图向下，场景无明显接缝与跳帧。

- 看得清镰刀蓄力、挥出、切断、收回；机械滚筒不是整车旋转。

- 前方饱满作物与后方整齐短茬形成持续可读对比。

- 主界面贴合参考图的圆润、饱满、柔和体积质感；工作区无UI遮挡。

- 金币浮字和声音不刷屏，连续看1分钟没有刺眼强闪或噪声堆叠。

至少一台Android和一台iPhone记录实际型号、构建和帧率；连续15分钟运行，目标大部分时间30 FPS以上，无崩溃或持续内存增长。未真机验证的项目明确标记未验证。

记录每级购买时间、净收割时长、过渡时长、每分钟实际收入、暂停次数、完整轮次数与帧率。用3—5人试玩观察是否愿意继续观看、是否看懂升级收益；小样本不代表市场留存结论。

# 12 下一步与完成定义

后续可扩展更高级机械、更多作物及环境主题，是否加入离线收益和商业化另行设计。持续维护“看着治愈、升级有变化”的目标，不重新加入搬运售卖负担。

MVP完成定义：玩家从一小垄青草开始，点击一次开始后自动持续收割，金币自动到账；通过四次升级到联合收割机，看到更大田地和不同作物，在全过程中不需操控方向、长按、搬运或出售，并可保存后继续观看。

旧V0.1 PRD与旧3D灰盒提示词中冲突的要求均以本版为准。本次交付为需求更新，尚未修改本地Cocos工程或重做UI素材。
