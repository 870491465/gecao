## 装配与实际参数

四张 PNG 原字节复制到 `assets/resources/cat-v01/textures/`，没有裁透明边、抠图、镜像、重新生成或逐件归一化缩放。运行时采用完整尺寸 SpriteFrame，`Sprite.trim=false`，保留透明度。

`CatPartsConfig.ts` 由源 JSON 生成，严格保持各部件原尺寸、锚点、位置、局部缩放和绘制顺序：左臂 → 右臂连刀 → 身体双脚 → 尾巴。共享纹理只加载一次。若重新导入，执行 `node tools/import-cat-parts.cjs`。

## 切割接触

`CatMotion.ts` 是实际动作参数和刀刃测量点配置。内刃测量像素包含 `(179,131)`、`(275,91)`、`(430,177)`；按列选择内刃上的不同点，不再用旧几何镰刀的 170 半径或任意结束回调发钱。

手工阶段的垄在右前方工作区，视觉中心 X=123，宽度 84 / 93，行间距 28；一级 2 列、二级 3 列全部在真实刃线覆盖内。身体地面锚点仍固定，地图只向下移动。窄垄的作物、田边和地面使用同一推进坐标。逻辑列数、行数、垄数、单价、处理速度和升级价格不变。

这是对该素材只能侧向小幅挥动的适配。如果需要重新覆盖猫正前方的宽垄，应补适配透视的手臂关键帧或进一步拆层，不能直接放大旋转角度。

一级与二级目前共用这一套右臂连刀 PNG；素材包不支持独立更换刀具。独立长柄镰刀、步行、扭腰及机械驾驶姿态需要后续配套素材。机械阶段继续使用原灰盒部件，本次没有把带完整脚部的身体强行拼进驾驶舱。
