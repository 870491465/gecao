# 大幅挥镰分层补充包 V0.3

本包提供 7 张独立透明 PNG 和人工选取的关节参考点，供已有 Cocos 2D 项目继续制作动作。是静态美术补充包，不是已绑定骨骼或已完成的大幅挥刀动画。

## 部件

- cat_head：独立后脑与耳朵，有颈部重叠区。
- cat_torso：无头无脚躯干，可小幅扭动。
- right_upper_arm：右上臂，肩到肘。
- right_forearm：右前臂，肘到腕。
- right_grip_paw：独立握爪覆盖层，带一段橙色腕部；腕部应与前臂重叠，不要把它当成额外一整段手臂伸长。
- sickle_inward：独立内勾镰刀，保持刀柄穿过手掌下方。
- right_arm_reach：前伸弯臂备用整层，已经包含手掌，使用时隐藏上臂、前臂和独立握爪，避免重复手臂。镰刀仍单独显示。

复用 OrangeCat_Walk_V02 的左右腿、左臂、尾巴，替换其中 cat_body 与 cat_right_arm_sickle。新素材不是与旧身材逐像素相同，需要校正头身比例、颈部重叠和肩部位置。不得把原合体身体和新头部再次叠加。

## 坐标与绑定

joint_reference.json 中的 suggested_points 是图内人工参考点，不是经过动作验收的骨骼。pixel_top_left 为左上原点像素坐标，normalized_bottom_left 为左下原点归一化坐标。保持 PNG 原始尺寸和裁切偏移。

推荐节点：固定 CatRoot 下放左右腿；UpperBody 下放躯干、头、左臂、尾巴和肩部枢轴。右上臂由肩部枢轴控制，前臂挂到肘部枢轴；握爪和工具共享 GripRoot。工具绘制在握爪下面，手掌应盖住握点，柄的两端可以露出。旋转工具时绕 grip，不绕图片中心。

手臂原始像素长度不代表最终解剖长度，不能将各 PNG 不加缩放串联。先按现有猫的肩到手距离缩小上臂和前臂，再定位手掌。肩、肘、腕截口需互相覆盖，禁止露出断面。头部 neck 覆盖 torso neck 附近，避免脖子拉长。

同一个前伸动作可能要求手臂藏在头部和躯干后方，而刀刃在其外侧露出。通过独立显示层或在动作关键点调整渲染顺序实现，不要让整把刀无条件压在猫脸上。

## 动作制作顺序

先禁用刀光。固定脚底、地图暂停，检查以下四个静态姿势，再插值：

1. 右侧蓄力：肩向后，肘弯曲，右手带刀在身体右侧外展。
2. 前伸接触：肩向前，肘展开，刀刃到草垄上缘；必要时使用 right_arm_reach 替换，手掌握点与工具世界位置必须对齐。
3. 向内拉切：肩和肘配合，内凹刃扫过当前垄宽。不能通过水平翻转整个角色实现。
4. 回收：刀远离草丛，回到蓄力前姿态；此阶段不再次结算。

可先试一轮 1 秒：蓄力 0.2、挥出 0.2、余势 0.15、回收 0.45。没有给固定旋转角度，因为应由实际关节位置、目标刀幅和前后遮挡决定。用参考点构建的平面骨架并不自动获得正确的三维透视；大幅转向仍可能需要更多手臂姿势。

躯干仅轻微扭动，头部可以反向补偿保持朝上；双腿不作为躯干子节点，保持原先脚底位置。先做动作再接地图，地图与迈步暂停时要一起停止，避免滑步。

## 验收

- 全程右手持刀，不换手；柄不脱离握点。
- 刀刃朝向拉切区域，不穿头、耳朵或躯干。
- 禁用刀光也能看清蓄力和扫割，扫幅覆盖当前逻辑垄。
- 肩肘腕无明显断口，替换整臂没有跳位或双手。
- 双脚在挥刀阶段固定；地图停下后才站稳挥刀。
- 切割事件只触发一次，刀光和碎屑不产生收益。

已检查 7 张 PNG 的透明通道与部件外观。尚未完成拼装动态验收、Cocos 测试或真实刀幅覆盖测试。right_arm_reach 是候选备用姿势；如果不能自然衔接，应保留两段式动作并反馈录屏，不能硬切造成跳变。
