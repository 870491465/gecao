- 入口：`assets/scenes/Main.scene`。样机仍可打开 `SwingSequenceLab.scene`，禁刀光、单刀和关键相位检查。
- `assets/scripts/V03Motion.ts`：`COMBINED` 记录图片路径、画布 571×580、支点 `(137,480)`、绘制握点和刀刃接触点 `(430,177)`；两级显示缩放 0.24 / 0.28。合体图画布和旧独立镰刀不同，不能直接比较旧缩放数字。

- `ManualSickle.ts`：重新按合体图实际轨迹计算两/三段接触相位，回刀不触发收益。`HybridCatActor.ts`、`HarvestGame.ts`、`AnimationDebug.ts` 的显示标注改为 V01 合体握刀。
- 保留单条草垄、草和猫大小、左臂配合动作、固定脚底、自动推进、经济、购买和存档流程。右臂随蓄力、前伸拉切、余势和回收转动，不旋转整张猫。
