# 橘猫割草记：装备栏 UI 素材 V01

本包仅包含底部五级装备栏，不是整张主页的全部资源。工具图标根据已确认的主页重新生成彩色独立图，非原图逐像素抠图。机器统一使用绿色与米白配色。

## 文件
- 5 张彩色工具图标和 5 张对应灰度图：512×512，RGBA。
- tile_normal.png：512×512 空白底板。
- selection_border.png：512×512 透明选中描边。
- active_dot.png：96×96 当前装备绿点。
- lock.png：128×128 锁标记。
- preview.png：上排全部解锁，下排当前为一级的拼装预览。
- equipment_config.json：等级与资源路径、布局建议。

## 等级顺序
1 小镰刀；2 长柄镰刀；3 手推收割机；4 骑乘收割车；5 联合收割机。
3～5 级为带间隔横杆的镂空拨禾轮。图标是静态整机，不含可转动的滚筒分层。

## Cocos 接入
在现有 Cocos 版本中导入 textures。创建固定于屏幕底部的 EquipmentBar，放在开始/暂停按钮上方，不随地面滚动。
每项分层：底板、工具图标、等级 Label、状态边框、锁或绿点。等级数字与文字不烘焙进贴图。
375 逻辑宽度参考：方块44，间隔8，整排252，与主按钮间隔14。工具图标约35×35，居中略向下，顶部留给等级和锁。
所有 PNG 使用中心锚点。普通底板与选中边框用相同大小，等比缩放；不要直接九宫格拉伸工具图。
低于当前等级：彩色；等于当前等级：彩色+描边+绿点；高于当前等级：灰度+锁。
可以切换 _gray.png，或使用工程已有的灰度材质；两种方式二选一。升级时更新显示状态，不重复扣费；扣费与升级逻辑沿用现有系统。
这排仅显示装备进度，点击查看信息；实际升级仍使用头顶气泡。

## 检查与限制
已检查14张PNG可读取、具有透明通道，并制作拼装预览。未做Cocos实机验证。
手推机与联合收割机边缘带轻微柔光，米白底板上较柔和；若放到深色背景，需另行处理边缘。
本包不含场景用整机、猫操作机械的姿势、拨禾轮动画或动画支点。不要把UI整机图直接作为场景动画资源。
素材由内置图像生成工具按主页参考生成，再统一画布并导出灰度版；状态标记为简单几何绘制。
