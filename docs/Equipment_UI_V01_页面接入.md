# Equipment UI V01 页面接入

最新交互以 [精简收割界面](精简收割界面.md) 为准：运行中隐藏大按钮、右下小暂停，头顶改为满足金币条件才出现的纯道具图标。以下为首版接入记录。

按用户提供的首页参考图优化 `assets/scenes/Main.scene`，保留当前单垄、猫、双手比例、单图挥镰、成熟草和 Batch02 草茬。

## 页面与素材

- 顶部：金币在左，当前设备在右，设置按钮在右上；另保留一行低干扰的等级、作物和整田进度。
- 猫头顶：米色升级气泡，显示下一设备图、绿色箭头、金币和实际价格；底部注明作物、单元收入与“收割时约”收入变化。有钱时边缘轻亮，点击才升级。
- 底部：五级装备卡，使用 `Equipment_UI_V01` 的底板、五张彩图、五张灰图、选中边框、绿点和锁。当前设备有边框及绿点，已解锁为彩色，未解锁为灰色加锁。卡片只查看信息，不切等级、不扣款，实际升级由头顶气泡完成。
- 主按钮：使用包内 `button_green.png`，文字与播放/暂停符号独立绘制，分别显示“开始割草”“暂停”“继续割草”。点一次后沿用自动收割流程。
- 金币、齿轮和升级气泡采用 Cocos Graphics 分层绘制；地面继续使用 Batch02。底栏机器图片仅用于 UI，场景机器仍保留现有独立工作部件，不把静态整机图拿来转动。
- 长屏时 HUD 向顶边调整，装备栏和按钮向底边调整；地面增加一个下方缓冲段，避免出现底部单色空带。只有背景缓冲变化，没有新增一垄草。

共复制 15 张原 PNG，源文件位于 `docs/Equipment_UI_V01/textures/`，运行资源位于 `assets/resources/equipment-ui-v01/textures/`，已逐一验证 SHA-256 相同。配置 JSON 同目录保存。图标与普通卡片均按完整画布等比显示，不烘焙等级数字。

## 行为和配置

经济、购买锁、存档、暂停和后台规则保持原有模型。参考图的 1,280 金币、200 价格是示意，不写入正常存档；初次进入仍为 0 金币 / Lv.1，一级升级价仍是 120。

## 验证

实际证据位于 `docs/verification/equipment-home-ui/`：`main-ready.png`、`main-running.png`、`level2-ui.png`、`highest-ui.png`、`mobile-390x844.png`、`results.json` 和 `build.json`。`upgrade-affordable-debug.png` 的 1,280 金币为标记过的调试场次，仅用于检查有钱状态。

Creator 3.8.8 Web 构建成功（退出码 36）；已实际查看 720×1280 与 390×844 页面、运行、二级和最高级状态，截图无底部空带。长屏布局计算高度约 1558，HUD 与底部按钮分别向边缘调整，猫和田地推进坐标保持不变。

实际通过：初次零金币、五卡彩图/灰图/锁和绿点、卡片不购买、金币不足不扣款、单次开始后持续运行、暂停无收入、连点六次升级只提交一次（1280 → 1160、仅升到二级）、暂停前升级后仍暂停、音效开关、最高级继续运行、后台返回不补钱。ReferenceLayoutLab 的开始入口、正常存档继续和连点只加载一次也复测通过。控制台无页面异常。

核心自动测试仍覆盖结算、购买锁、存档恢复和低帧率一致性。`video/` 保存实际操作录屏，含标记过的调试金额检查。真机安全区、声音听感及 15 分钟性能未验证。
