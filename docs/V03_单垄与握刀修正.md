# V03 单条草垄与握刀修正

按用户最新反馈调整：镰刀适当缩小，草保持此前大小，只排一条草垄供猫收割。此记录取代 V03_Rig 接入记录中的 400 / 420 宽田参数。

改动：

- 镰刀显示缩放从 0.28 改为 0.21，缩小 25%，不拉长刀柄。
- 修正腕部绑定：此前前臂末端错误地延伸到刀柄握点，相当于穿过握爪。现在增加 V03Wrist，前臂终点接握爪腕部，握爪再延伸至刀柄。上臂、前臂、腕、掌与刀各用原有 V03 PNG。
- 手掌缩放 0.085，前臂骨长 24；握点仍位于刀柄 `(227,622)`，手掌覆盖刀柄。实际握点与腕部各自验证，不能仅验证两个锚点相等就认定握姿正确。
- 一级、二级都使用一条居中草垄，作业范围 180 设计像素。草图画布仍为此前一级 284、二级 218，保持草的原有大小与高度。
- 每行只拼一丛完整草，逻辑上的两/三列分别对应同张草图不重叠的横向区域。刀刃从右向左经过时逐段倾倒，不再并排两/三张大草图。
- 保留原作物 ID、单价、每行结算数、升级价、存档 mask 与自动换垄/轮流程。一级每行仍收入 2、二级每行仍收入 6；同一行的草图使用同一变体，避免拼接成不同草。

主要配置：`assets/scripts/V03Motion.ts`；腕部绑定：`V03Actor.ts`；单条草图显示：`Field.ts`。机械等级不受此调整影响。Creator 保持 3.8.8。

入口为 `assets/scenes/Main.scene`。停止旧预览并重新预览以加载新脚本；动画检查入口在齿轮设置内，也可打开 `SwingSequenceLab.scene`。当前仍是 V03 分层关节动画，未冒充正式序列帧。

验证证据位于 `docs/verification/v03-single-strip/`。Creator 3.8.8 Web 构建成功；实际 WebGL 检查 101 个姿势的肩肘腕掌接合及握点对齐通过，中途暂停冻结播放和进度。一级连续两轮 160 单元 / 160 金币，无重复 ID；二级两次 0.5 秒跨帧推进切三段，收入 6 金币；实际刀刃与接触位置误差小于 0.001 设计像素。完整自动检查也涵盖购买锁、存档恢复和低帧率收入一致性。

`running.png` 是当前单条草垄运行画面，`pose-*.png` 是禁用刀光的姿势检查，`video/` 为实际运行录屏（包含调试步骤）；`results.json` 保存原始测量数据。微信真机、声音听感及 15 分钟性能仍未验证。
