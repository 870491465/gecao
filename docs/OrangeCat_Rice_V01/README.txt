水稻素材 V01｜橘猫割草记

textures：3个成熟水稻变体、1个连排素材、1个稻茬、5个稻粒、3个碎叶，共13张透明PNG。
rice_reference.png：已确认的素材参考图。field_preview.png：三垄拼装示意，不代表联合收割机最终垄数。

替换草素材：
1. 将textures导入Cocos，纹理作为SpriteFrame使用。成熟水稻与稻茬均为512×640，锚点统一(0.5,0.05)，对应根部落地位置。采用CUSTOM尺寸，保留完整画布；避免按透明裁边后的尺寸改变节点大小。
2. 原有草节点使用rice_mature_01～03随机变体，保留原有生成、回收、地图滚动和收割判定逻辑。仅在农作物升级到水稻后切换资源。
3. 以田垄宽度控制整体缩放，水稻叶片宽度约占单垄宽度80%～95%，不要直接用512像素原尺寸。前后叠放，以根部位置排序：屏幕下方的植株覆盖上方植株。不要用稻穗顶部作为碰撞点。
4. 收割时成熟植株隐藏，替换为同尺寸同锚点的rice_stubble；稻粒与碎叶用作短暂飞散粒子。碎片不要当作整株素材。
5. rice_row_strip仅用于背景密植或整段收割；逐株判定请用三个单丛变体，不要同时叠放两套导致密度过高。连排素材锚点见assets.json。
6. UI金币和作物收益由游戏配置控制，本包不包含或修改经济数值。

图片说明：成熟水稻为金黄下垂稻穗与青绿叶片，稻茬已缩小高度；所有植物PNG底部留32像素透明边。颗粒素材保持各自完整画布。
检查：独立透明通道、尺寸、PNG解码和ZIP完整性检查通过。未接入用户Cocos项目，实际缩放与遮挡仍需在现有场景中确认。
