# UI 原型优化 V1

依据用户提供的竖屏 UI 原型调整，继续使用 Cocos Creator 3.8.8 原生 2D。入口仍为 `assets/scenes/Main.scene`，编辑器等待资源导入后预览；`ScytheLab`、`GrassFieldLab` 可单独观察同一套新构图。

## 本次调整

- 左上改为金币胶囊与当前设备胶囊，右上设置齿轮；田地名称、轮次、进度收成一条小进度带。
- 升级卡移至角色前方，显示下一设备、对应作物、单元收入变化、标明“收割时约”的收入、金币购买进度与购买按钮。最高级保留持续收割提示。
- 底部统一开始、暂停、继续按钮。声音开关移入设置，开发入口仅 Debug/DEV 可见。
- 猫居中，主玩法统一缩放从 0.26 改为 0.17（约原来的 65%），固定脚底根节点 Y=-205，一级与二级保持相同体型，不随田地扩张继续缩小。
- 一至五级垄宽为 360/390/420/460/500；一级种植土带宽为 392，约占 720 设计宽的 54%。原有列数、行数、垄数、单价、购买价格与行/秒不变。
- 一级草图完整画布改为 255×255，行距 42，保持源素材锚点和同字母短茬配对。扩大前后缓冲，草、短茬、田边仍共用距离。地面双段高 1536，覆盖完整 1280 高视口。

## 宽垄动作与素材限制

V02 的右臂和镰刀是一张一体 PNG，原角度设计适合右侧窄田。缩小猫后无法同时覆盖居中宽垄，因此主玩法换为独立肩部、前臂、握点、长柄和弧形刀刃的 **Graphics 占位工具**，保留原 V02 身体、腿、左臂和尾巴。仍按蓄力 0.2s、挥出 0.2s、余势 0.15s、回收 0.45s 分段；刀具从左前方扫向右前方，猫根节点不移动。当前刀具造型与正式猫图的质感还不完全一致，后续应换为独立手臂/刀柄/刀刃素材。

`CatPartsLab.scene` 保留原始六层 PNG 的静态、走路和一体镰刀样机，不修改源包。原 V01/V02、Batch02 接入记录中的窄垄尺寸是历史参数，本记录为当前主玩法参数。

刀刃接触点使用实际肩部旋转与刀具长度计算，收割事件在跨过关键相位时触发。单步跨越多个事件时，依次临时使用准确接触相位派发事件，再恢复目标相位；回收仍受原 mask 去重限制。金币仅由模型切割事件发放。旧存档沿用同一版本和经济进度，地图距离单位仍为行。

## 配置与替换

- `assets/scripts/WideScythe.ts`：主玩法猫比例、固定位置、垄宽、工具长度、挥扫角与接触计算。
- `assets/scripts/WideScytheActor.ts`：独立前臂、刀柄、刀刃与挥扫线；替换其子节点美术时保持肩部、Blade 原点及接触数学一致。
- `assets/scripts/HarvestGame.ts`：UI 布局、购买卡与按钮交互；`EquipmentIcon.ts` 为几何图标。
- `assets/scripts/GrassLayout.ts`：草簇显示尺寸、地面循环段、碎屑上限；`Field.ts` 为可视缓冲与排序。
- `Config.ts` 的三至五级宽度只影响显示与设备外形，经济数值未调整。
