# 小镰刀短刀光补充包

fx_sickle_slash.png 是带柔和 alpha 的独立刀光贴图，浅金边缘、暖白中心，不含黑底。画布尺寸见 asset_config.json。贴图已去掉大面积空白，保留透明边距。此包补充第二批草地资源，不覆盖旧文件。

接入现有 Cocos 2D 项目，不改引擎版本：

- 创建独立刀光 Sprite，用中心锚点，放在镰刀实际切割弧线位置，不放在猫的脚底或头部中央。
- 初始显示宽度取刀刃一次有效扫过宽度的约 0.7–1 倍，保持图像比例；不要铺满全屏。朝向按实际挥刀方向校准，可旋转或水平镜像以匹配亮端方向。
- 刀光应位于切割区作物上方，避免覆盖猫的脸、身体和 UI。先用普通 alpha 混合，确认背景透明后再考虑加色，防止过曝。
- 挥刀接触草丛时出现，建议总时长 0.12 秒：0–0.02 秒淡入，0.02–0.05 秒保持，0.05–0.12 秒淡出。可同时把横向缩放从 0.8 增至 1.0，但不要不停旋转形成光环。
- 一刀最多显示一次刀光，粒子与刀光不能再次结算金币。暂停或取消攻击时隐藏并复位，复用节点而非反复创建。
- 这是一张静态特效图，不是序列帧动画；淡入淡出和位置跟随由项目实现。

已检查 RGBA 透明通道。时长、尺寸、层级是联调起点，尚未在 Cocos 或手机上验证。
