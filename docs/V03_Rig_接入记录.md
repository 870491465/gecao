# V03 分层挥镰与 Main 宽田

本次按“用 V03 的素材来做”接入，保持 Creator 3.8.8。当前是 V03 静态部件绑定的关节动画，**不是完整挥镰序列帧**。经济、购买、存档、自动换垄与换轮仍使用原有 HarvestModel；只更换手工收割的显示与接触几何。

## 资源与入口

- `OrangeCat_Swing_V03`：头、躯干、上臂、前臂、握爪、内勾镰刀六张原 PNG 实际使用；备用整臂 `right_arm_reach` 未加载，避免重复手掌。
- `OrangeCat_Walk_V02`：沿用左右脚、左臂、尾巴及距离步态。旧合体身体和带镰刀右臂隐藏。
- `Sickle_Slash_Addon`：独立刀光，默认关闭，方便看清动作本体。
- `Grass_Field_Batch02`：成熟草、地面、池化草屑；宽田已割区域改为细茬占位 Graphics，每个逻辑单元绘制多根细茬，细茬没有额外结算 ID。
- 合格整套挥镰序列帧仍缺失；不使用此前换手、偏位姿势图。

打开 `assets/scenes/Main.scene`，预览后点一次“开始收割”。一、二级已是可玩的居中宽田，不必进入参考构图场景。`SwingSequenceLab.scene` 和 `ScytheLab.scene` 可独立看 V03；样机场次不覆盖 Main 存档。Main 齿轮设置 → 动画检查，可单刀、循环、暂停、关键相位单步、显示锚点/轨迹、关闭草屑和刀光。

CatRoot 固定在设计坐标 `(0,-205)`，脚底为唯一基准。上臂/前臂骨长为 42 / 40；握爪缩放 0.11，腕部与前臂重叠；镰刀缩放 0.28，旋转后 Y 投影为 0.65。握爪与刀具共享 GripRoot，刀柄先画、握爪后画，头身覆盖穿过其背面的手臂与刀柄。躯干只轻扭 ±2.5°，头部保持向上。身体、手臂、刀具分别运动，不旋转整张猫。

一、二级逻辑垄宽分别 400 / 420，行距 44。刀刃有效接触从右向左扫过列根部：一级列中心 ±100，二级 ±140 和 0。每行仍只结算 2 / 3 个原有逻辑单元，不把显示草叶数量当收入。0.20s 蓄力、0.20s 挥出、0.15s 余势、0.45s 回收与迈步；挥割地图停稳，回收阶段推进至下一行。回刀和特效不结算。

## 正式美术替换

替换部件时保留 PNG 透明画布，按 `joint_reference.json` 校正 `V03Actor.ts` 中肩/肘/握点及 `V03Motion.ts` 的比例与内刃坐标，随后重新跑关节和接触测试。不要把握爪腕部再当第三段手臂，也不要同时显示备用整臂。

未来正式序列 PNG 放入 `assets/resources/cat-swing-sequence/frames/`，逐帧配置在 `sequence.json`，示例为同目录 `sequence.example.json`。示例默认禁用且没有对应图片，轨迹仅演示数据格式，不能作为已验收动画开启。正式素材到位后必须重新测量刀刃轨迹、统一脚底锚点与身体高度；现有 WalkVisual / SwingVisual 互斥播放模块保留。

## 验证与边界

Creator 3.8.8 隔离副本 Web Mobile 构建成功（退出码 36）；没有关闭或覆盖用户打开的编辑器。实际截图、录屏及机器可读结果在 `docs/verification/v03-rig/`。

已通过 TypeScript、既有结算/购买锁/存档恢复/低帧率自动测试，以及 V03 原图完整性、固定骨长、1001 个相位不超出 IK 范围、单调刀刃轨迹、一二级全部列覆盖和回收首尾连续性。WebGL 中检查 101 个姿势的肩肘腕连接和共用握点；暂停后冻结播放与进度；一级连续两轮准确切 160 单元、收入 160，无重复 ID；二级两次 0.5 秒跨帧推进准确切三列、增加 6 金币，实际刀刃与判定位置误差小于 0.001 设计像素。约八秒正常播放期间桌面 WebGL 约 60 FPS，此数据不能替代真机长测。

`V03-walk-swing-pause.mp4` 为实际 WebGL 录屏片段，包含行走、挥割及底部暂停/继续；`pose-*.png` 为禁刀光静态姿势检查，`running.png` 为主场景运行截图。原始全程录屏包含调试姿势和加速验证，位于 `video/`。具体数据见 `results.json`。ReferenceLayoutLab 的开始按钮、正常存档继续、连点只加载一次、后台取消自动开始也在当前构建上复测通过，结果在 `docs/verification/reference-start/results.json`。

已有样机成长测试仍为：有钱即买，一级约 60.03 秒，二级约 121.95 秒，三级约 183.85 秒，四级约 245.15 秒；到五级累计约 610.98 秒。计入换垄的整田平均收入约 1.97 / 5.92 / 17.71 / 58.98 / 157.16 金币/秒。这是模型模拟结果，不是真机计时或本次动画观感验收。

仍未验证：微信真机、15 分钟稳定帧率与内存、真机声音听感。正式挥镰序列素材仍缺失。当前原图部件的大幅平面转动可见前后遮挡，尚不能获得序列帧的全部透视变化。

优先调整三项：实机慢放检查腕部重叠和刀柄遮挡；补齐统一锚点的正式挥镰序列；替换宽田细茬占位并细调成熟草密度。录屏场次与加速检查标为调试，不计入正常成长时间。
