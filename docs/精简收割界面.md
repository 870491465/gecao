# 精简收割界面

本次按最新交互要求调整 Main，保留单垄、角色动作、双手比例、成熟草与短草茬。

- 首次进入和暂停后显示绿色开始/继续按钮。点击后按钮隐藏，右下角显示小暂停按钮；点击小暂停后停止模拟，再显示绿色继续按钮。
- 道具栏整体下移，收割时进一步移入原大按钮空出的区域；暂停后为继续按钮留出空间。长屏按底部安全空间定位。
- 小猫头顶提示默认隐藏，金币达到下一等级价格才出现彩色下一道具图标。提示内没有设备名称、等级、价格、收入、箭头或金币文字。
- 点击图标购买下一等级，沿用原子扣款和换装流程。换装期间图标隐藏；完成后若余额仍足够下一次升级，再显示下一图标，仍需点击才购买。
- 升级前运行则结束后继续收割，大按钮保持隐藏；升级前暂停则结束后保持暂停，绿色继续按钮可用。最高级不显示升级提示。
- 初次进入依然是 0 金币，一级升级仍扣 120；金币不足时没有头顶购买入口。头顶详情的隐藏按本次用户指令执行，未改经济数值。
